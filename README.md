# Custom C++ Shell with PTY and Terminal Guard Support

A lightweight and efficient command execution module for a custom shell written in C++. This project provides full support for interactive applications (such as vim, nano, htop, or terminal games) by resolving issues with input buffering, raw terminal modes, and bidirectional communication.

---

## Main Features

* **Pseudo-Terminal (PTY):** Utilizes `forkpty()` to create a virtual terminal for child processes, allowing applications to function as if running in a native system terminal.
* **Terminal Guard (RAII Pattern):** Automatically switches the terminal into raw mode during application execution and reliably restores the original settings upon exit, preventing terminal corruption.
* **Asynchronous I/O (`poll()`):** Simultaneously monitors user input (`STDIN_FILENO`) and program output (`master_ft`) without thread blocking, ensuring smooth and instant response to keystrokes.
* **Cross-Platform Support:** Conditional compilation for macOS (`<util.h>`) and Linux (`<pty.h>`).

---

## Architecture and Operation

### 1. Terminal Guard (`TerminalGuard`)
A helper class utilizing the RAII (Resource Acquisition Is Initialization) pattern:
* **Constructor:** Retrieves the current terminal state using `tcgetattr()`, creates a backup copy, and enables raw mode via `cfmakeraw()` and `tcsetattr()`.
* **Destructor:** Restores the original terminal state immediately after the program terminates.

### 2. Bidirectional Loop (`poll`)
Instead of a traditional blocking read, the parent process uses the `poll()` function to monitor two channels simultaneously:
1. **Keyboard to PTY:** Keystrokes are intercepted and transmitted directly to the running process.
2. **PTY to Screen:** Data generated by the application is received and rendered onto the shell screen in real time.

## Requirements

* POSIX-compliant operating system (Linux or macOS)
* C++ compiler supporting C++17 or later
